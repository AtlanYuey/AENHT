# 条漫自动滚动修正：Issue #7 测试版

本文记录首次交付的 **0.2.1（构建号 4）** `dev` 测试包及当时的实现和检查结果。实测仍有高速抖动后，又进行了连续位移与帧内开销优化；后续版本策略和待确认项见 [0.2.2-beta.1 预发布说明](../releases/0.2.2-beta.1.md)。本文下方的源码、签名和哈希均属于首次测试包，保留作历史记录。

## 这次改了什么

1. **新增“滑动时继续自动滚动”开关**，放在自动滚动速度下方，默认关闭。关闭时手动拖动会停止自动滚动；开启后，自动滚动保持开启，手指拖动和惯性滚动期间由用户操作位置，结束后从实际位置接续。跳页、打开设置、后台、离开阅读器仍会暂停。
2. **快速档提示**：3 秒/屏及更快时，速度值与它前面的“可能速度过快，无法正常阅读”提示显示为红色；3.5 秒/屏及更慢时不显示提示。提示不禁止用户选择快速档，现有 1–30 秒/屏与半秒微调继续保留。
3. **修正滚动驱动**：iOS 不再每帧通过 SwiftUI 的位置绑定发出绝对定位命令，而是在屏幕刷新时从 UIScrollView 当前实际偏移前进。手动跳页单独使用 ScrollViewReader。自动推进按物理像素累计余量，布局校正后不会追回旧目标，不会与拖动和惯性抢位置。
4. **稳定长图高度**：两端保留已经解码得到的宽高比，避免懒加载行回收后退回占位尺寸，引起重新排版。预加载页数没有作为这次修复手段调整。
5. **上下栏保留正常计时**：连续阅读的页码变化不再直接隐藏上下栏；点击显示后，跨到新图片也不会提前隐藏，仍按用户配置的控件隐藏时间处理。实际拖动、手动关闭等原有操作继续生效。
6. **设置保存与同步**：新开关加入本地保存、备份导入和设置同步，从旧版本升级且没有保存过该开关时默认关闭；导入缺少该字段的旧备份时保留当前开关状态。

## 主要修改位置

- `iosApp/AENHT/Features/Reader/ContinuousReader.swift`：保留现有滚动视图和图片布局，接入新滚动驱动、显式跳页、加载及重试状态。
- `iosApp/AENHT/Features/Reader/ReaderScrollDriver.swift`：原生偏移、行坐标、用户操作接管、末页/失败停止、尺寸缓存。
- `iosApp/AENHT/Features/Reader/ReaderScrollMotion.swift`：物理像素余量、实际帧时间、卡顿位移上限。
- `iosApp/AENHT/Features/Reader/ReaderView.swift`：快速档提示、开关位置、上下栏隐藏条件。
- `androidApp/.../screens/Reader.kt`：开关、提示、手动滑动后接续、空闲帧推进、尺寸缓存及回归测试对应行为。
- 两端 `AppSettings`：新开关保存、导入和同步。
- 两端语言资源与 `tools/i18n`：14 种语言的新文案。
- `iosApp/project.yml`、`.github/workflows/ios.yml`：独立 iOS 阅读器测试目标，运行 UIKit/SwiftUI 模拟器回归测试；测试目标不依赖整套 Kotlin Framework。
- 两端构建配置：测试构建号升至 4。
