# 自动平滑滚动：使用说明与实机测试

对应需求：[#6](https://github.com/AtlanYuey/AENHT/issues/6)。随 0.2.1（构建号 3）发布。

## 使用入口

1. 打开作品的阅读器，在阅读设置的「阅读」页选择「上下连续（条漫）」或「上下连续（有间距）」。
2. 同一页出现「自动滚动速度」，范围 **1–30 秒/屏，新安装默认 10 秒/屏，支持 0.5 秒微调**。左慢右快，数值表示滚动一个阅读视口所需的时间；屏幕大小不同，读完一屏的时间相同。
3. 关闭设置，点击底部的「自动滚动」。再次点击「暂停自动滚动」即可停在当前位置。
4. 「我的 → 阅读」使用同一套设置。速度可保存、备份、导入和同步；旧版本的翻页间隔仍单独保留。

横向分页、竖向分页和双页继续使用原来的按间隔自动翻页。

「页面间距」只出现在「上下连续（有间距）」模式；双页使用固定 6 pt 中缝，不再提供横向间距设置。旧备份中的双页间距字段会忽略，条漫间距继续保存。升级时保留范围内的滚动速度，超过 30 秒/屏的旧值收敛为 30 秒/屏。

## 行为约定

- 按显示帧的实际时间计算距离；60 Hz 和 120 Hz 的目标速度一致。单次卡顿最多补偿 50 ms 的移动，后台回来不会追赶滚过未读内容。
- 手动拖动、页码跳转、打开设置、切换阅读模式、切到后台或离开阅读器会暂停。再次开始由用户点击。
- 图片正在加载时等待，加载完成并且真实高度完成布局后继续；失败时暂停并显示重试入口。重试成功后仍需点击「自动滚动」。
- 最后一张图只在**图像底部到达视口底部**时停止。显示「最后一页」不会提前停止一张还没看完的长图。
- 连续阅读的“当前页”与“跳转到某一页”分开管理，记录进度不会把画面拉回页首。历史仍按页号记录，不记录每个像素位置；重新打开作品按原有行为定位到记录页。
- 保留现有常亮设置，自动滚动不会绕过用户设定的自动锁屏策略。

## 长图与资源限制

Android 连续阅读不再把图片宽高比强制限制为 0.2–5；iOS 与 Android 会在图片加载后采用实际宽高比，包括站点起初没有提供尺寸的情况。

连续阅读的可见图片解码限制为适合 1400 × 8192 像素的范围。iOS 预加载仅缓存压缩数据到磁盘，Android 预加载使用同样的解码尺寸，避免在后台同时解码多张完整长图。极长原图可能降低清晰度；这一版没有新增连续阅读的图片分块解码功能。Android 为防止畸形尺寸超出布局约束，单张布局高度上限为 50,000 dp，超出这一上限的极端长图仍需后续专门处理。

iOS 在宽度发生变化（旋转、分屏）时暂停，视口由系统布局调整。高度变化（例如自动隐藏工具栏）不会把刚开始的滚动立即停掉。

## 已加入的自动检查

- 共享测试：60/120 Hz 相同速度、视口尺寸与速度换算、卡顿、非法设置、未加载图片边界。
- Android 设置测试：保存、重启读取、备份导入、旧备份兼容、非法同步数值、与翻页间隔互不覆盖。
- Android 真正运行阅读器与 Coil 的界面测试：长图末页仍滚动；手动拖动后暂停且位置不回页首；有间距模式在真实内容末尾停止；等待加载后按真实长图高度继续；失败后暂停、重试保持暂停、明确点击后继续。
- 原有双页及连续阅读的两次失败重试测试继续保留。完整测试、Lint 与构建结果见交付记录。

这些 Android 测试使用模拟数据和 Robolectric，并非 iPhone 实机测试。iOS 需要 macOS 编译检查，再由使用者安装测试包验证下面的项目。

## iPhone / iPad 实机重点测试

| 场景 | 应看到的结果 |
| --- | --- |
| 两种连续模式，短图、长图和混合尺寸 | 匀速滚动，无逐页跳跃或页首吸附 |
| 1、1.5、10、30 秒/屏；60 Hz 与 ProMotion | 调速方向正确，一屏时间大致吻合；观察是否抖动或费电 |
| 读到最后一张很长的图 | 继续滚动至图像底部后才停止 |
| 播放中手动拖动、页码滑块、前后页、输入页码 | 自动滚动停止；继续播放从当前画面开始 |
| 打开设置、关闭设置、切换模式 | 暂停；关闭设置不会擅自继续 |
| 锁屏、后台、返回、退出后再次打开 | 暂停；没有补滚或自动恢复 |
| 慢网、断网、加载失败、重试、重新联网 | 等待或明确暂停；不会跨过未加载的内容；可以重试 |
| E-Hentai 初次加载才知道真实尺寸的长图 | 真实高度生效后继续，不能把初始占位高度当成末尾 |
| 已下载离线作品 | 可以自动滚动，不依赖联网请求 |
| 横竖屏、iPad 分屏、切换图间距 | 不跳到错误页；检查旋转后的可见位置是否符合预期 |
| 原分页、双页、自动翻页 | 原来的翻页间隔与方向正常 |
| 恢复 App、设置备份、WebDAV 与 iCloud 设置同步 | 滚动速度保留；运行/暂停状态不跨设备传播 |
| 多张极长图连续阅读 10 分钟以上 | 观察清晰度、内存、温度、帧率和加载边界 |

## 测试包与签名

iOS 测试包使用本次用户提供的开发证书和描述文件，在本地签名。密钥、密码和描述文件不提交到 Git，也不上传到构建任务。包内必须包含描述文件才能安装；签名包仅交付用户，开发版公开下载仍是构建流程生成的未签名包。

仅描述文件已登记的设备可以安装，需要 iOS/iPadOS 18 或更高版本；开发签名需要启用开发者模式。测试不等于已完成实机验收，正式发版前仍需核验上表。
