## 0.2.5

### Android 手机
- [ ] 快速来回切换标签，特别是连点「我的」后再点「主页」：不再闪退。
- [ ] 快速点开「历史」里的作品后立刻点「主页」，再回到「历史」：作品页不会卡在半路。
- [ ] 「我的 › 账号 › 用 API Key 登录」：输入框在输入法上方，没有被挡住。

### 阅读器（Android 和 iPad 都要测）
- [ ] 底部控制栏只有一行（当前页 / 总页数、进度条、剩余页数），上下留白相同，没有左右箭头。
- [ ] 按住进度条拖动：页码实时变化；上方出现 5 张缩略图（前 2、当前、后 2），跟着手指移动；松手后跳到那一页。nhentai、E-Hentai、已下载的作品都试一下（E-Hentai 没看过的页，手指停一下后才出现缩略图）。
- [ ] 两侧按钮：两个都开时，自动阅读和阅读设置分在左右两侧；「自动阅读按钮位置」选左 / 右能对调；选「跟随手的位置」时，从左边点出控制栏，自动阅读在左，从右边点出则在右。只开一个时，它出现在你点击呼出控制栏的那一侧。
- [ ] 放大过页面时「重置大小」出现在中间；右上角菜单里仍能打开阅读设置。
- [ ] 打开「仅点击中间呼出控制栏」：条漫（连续）模式点两侧不呼出，点中间呼出；分页模式关闭「点击翻页」后同样如此；页面放大时也一样。关闭这个开关后恢复原样。

- [ ] iPad：E-Hentai 作品页点一下收藏（心形）直接展开收藏夹；点一下评分直接展开评分；未登录时点一下去登录。
