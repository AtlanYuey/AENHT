# 待测试清单

开发者自己在设备上还没测过的改动。测完一项就删掉一项。

## 0.2.6

### Android 手机
- [ ] 快速来回切换标签，特别是连点「我的」后再点「主页」：不再闪退。
- [ ] 快速点开「历史」里的作品后立刻点「主页」，再回到「历史」：作品页不会卡在半路。
- [ ] 「我的 › 账号 › 用 API Key 登录」：输入框在输入法上方，没有被挡住。
- [ ] 弹出输入框或菜单时按返回键：先关闭它们，下面的页面还在。
- [ ] 在浏览器复制 E-Hentai 的 Cookie，再打开「用 Cookie 登录」：三栏自动填好；粘贴到任意一栏也会自动拆开；「粘贴 Cookie」按钮可用。
- [ ] 如果还有闪退：重新打开应用，看「关于 › 诊断」里有没有记录。

### iPad
- [ ] 在 Safari 复制 Cookie 后打开「我的 › 账号 › 用 Cookie 登录」：三栏自动填好（iOS 可能会问一次是否允许粘贴）；「粘贴」按钮和粘贴到任意一栏都可用。

### 阅读器（Android 和 iPad 都要测）
- [ ] 底部控制栏没有左右箭头；自动阅读、重置大小（调整过页面大小时）、阅读设置按钮都还在。
- [ ] 打开「阅读设置 › 操作 › 控制栏 › 精简控制栏」：底部只剩一行进度条，下面是「当前页 / 总页数」和「剩余 N 页」；拖动进度条能跳页。
- [ ] 精简模式下分别打开「阅读设置按钮」「自动阅读按钮」：圆形按钮悬浮在进度条左上方，能用；放大过页面时「重置大小」也在那里；右上角菜单里仍能打开阅读设置。
- [ ] 打开「仅点击中间呼出控制栏」：条漫（连续）模式点两侧不呼出，点中间呼出；分页模式关闭「点击翻页」后同样如此；页面放大时也一样。关闭这个开关后恢复原样。
- [ ] 阅读设置三个分页（阅读 / 显示 / 操作）：原来的每一项都还在，只是位置变了；「我的 › 阅读」里也一样。

### 收藏和历史（Android 和 iPad 都要测）

- [ ] 长按作品菜单里的「选择」：进入多选并已勾选这个作品。

- [ ] 多选时底部标签栏隐藏，选择栏不挡住最后一行作品；Android 按返回键退出多选。
