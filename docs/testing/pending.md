### 阅读器（Android 和 iPad 都要测）

- [ ] 按住进度条拖动：页码实时变化；上方出现 5 张缩略图（前 2、当前、后 2），跟着手指移动；松手后跳到那一页。nhentai、E-Hentai、已下载的作品都试一下（E-Hentai 没看过的页，手指停一下后才出现缩略图）。

- [ ] 放大过页面时「重置大小」出现在中间；右上角菜单里仍能打开阅读设置。

- [ ] iPad：E-Hentai 作品页点一下收藏（心形）直接展开收藏夹；点一下评分直接展开评分；未登录时点一下去登录。

### 作品页打开（Android）
- [ ] 从主页、收藏、历史、搜索点卡片：卡片上的封面和标题直接飞到作品页的封面和标题位置（不重新加载、不闪），作品页在周围淡入；返回时飞回卡片。同一作品在一页里出现两次时，从你点的那张飞出。从链接打开（没有卡片）时照旧从侧边滑入。
- [ ] 展开时不卡顿：动画中只有封面和标题，动画结束后其余内容淡入。
- [ ] 从作品页的页面缩略图打开阅读器（安卓和 iPad）：放大过程中一直是那张缩略图，不会先变空白再转圈；大图到了以后原地变清晰。翻到还没下载的页时也是先显示缩略图。
- [ ] 开着超分辨率看一阵：不再出现满屏花屏；如果「关于 › 诊断」里出现 super-resolution 的记录，说明这台手机的 GPU 结果被拦下并改用了 CPU。
- [ ] 阅读器底部进度条可以顺畅拖到任意位置；阅读设置里的各个滑块（亮度、间隔、速度）也能正常拖。

- [ ] 默认：底部一行三个气泡——左边阅读设置、中间进度栏、右边自动阅读；手机和平板都是这样，不跟随手指。

### 长按页面重新加载（Android 和 iPad）
- [ ] 阅读器里长按一页（手指不动约半秒）：在手指的位置弹出「第 N 页」菜单，有「重新加载此页」「保存页面」「分享页面」。
- [ ] 在页面左右两侧（点击翻页的区域）长按：只弹菜单，松手后不翻页。
- [ ] 断网打开没缓存的页：失败的位置出现带刷新图标的「重新加载此页」，联网后点一下就加载出来（分页、双页、条漫都试）。

- [ ] 长按不会误翻页，也不会弹出控制栏。
