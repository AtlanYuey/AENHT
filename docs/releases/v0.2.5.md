0.2.5 是 Android 的紧急修复版本：打开作品详细页闪退（#12）。iPhone / iPad 没有功能变化。

## 修复

- **Android：打开任何作品详细页都会闪退**（#12，感谢 @DUYA666 的详细报告）。「其他版本」用到的一条正则表达式里有一个没转义的 `}`：电脑上的 Java 能接受，Android 的正则引擎（ICU）会拒绝，导致详细页一打开就闪退。这个问题从 0.1.0 起就存在，现已修复，并在 Android 15 模拟器上验证。
- **Android：登录页（nhentai、E-Hentai）和 E-Hentai 设置页**：
  - 网页不再被画进顶部玻璃栏的模糊层。在部分手机上，这会让网页不停闪烁。
  - 不再显示底部标签栏。之前标签栏会挡住网页底部，包括 Cloudflare 的「验证你是人类」勾选框。

## 测试改进

- Android 版之前的自动测试都跑在电脑的 Java 上，测不出这类只在真机上出现的问题。现在每次提交都会在 Android 15 模拟器上运行真机测试：检查所有正则表达式能否在 Android 上编译、登录页能否正常打开，并保留录屏和日志。另外，所有正则表达式也会直接用 ICU 编译检查一遍。

## 安装

| 平台 | 文件 | 要求 |
| --- | --- | --- |
| Android | `AENHT-0.2.5.apk` | Android 10 及以上 |
| iPhone / iPad | `AENHT-0.2.5.ipa` | iOS / iPadOS 18 及以上 |

Android APK 使用项目正式证书签名，可覆盖安装；公开的 iOS IPA 为未签名包，请用自己的 Apple ID 签名后安装。
