# AENHT 0.2.1 小修订（构建号 6）

本次沿用 **0.2.1**，仅递增构建号，不创建新的语义版本或 beta 标签。日常小修订通过现有 `dev-latest` 下载入口滚动更新，保留此前正式 `v0.2.1` 的标签和文件。

## 已完成的调整

1. 阅读设置中，自动滚动速度下方新增“滑动时继续自动滚动”，默认关闭。打开后，手动拖动和惯性期间由用户控制位置，结束后继续自动滚动。开关支持保存、备份和同步。
2. 3 秒/屏及更快时，在速度值前显示红色“可能速度过快，无法正常阅读”，数值也使用红色。
3. 条漫跨图不再立即隐藏上下栏，按设置的隐藏时间处理。
4. 保留已经解码的图片尺寸，并减少 iOS 重复的坐标扫描、锚点分配；位移仅补偿系统像素取整造成的小误差，不追回加载或布局校正形成的大偏移。
5. 修正版本比较及显示，保持后续版本检查的正确性。当前版本显示为 `0.2.1 (6)`，没有 beta 后缀。
6. 整理阅读器视图的计算属性，以缩短编译器需要推断的单个表达式；修饰器顺序和现有界面行为保持一致。

## 明确未解决的问题

**高速自动滚动的卡顿/抖动在实测中仍然存在，目前暂未找到可靠的解决方法，问题暂未解决。** 本轮停止继续调整滚动方案，先保留 Issue #7，后续有进展再更新。上面的位移和计算调整不能视作已经解决了实机卡顿。
